# Hyperscale

The operating system for financial products.

Build a financial Product in HSX. The compiler turns your program into UDL,
the contract Hyperscale executes. Your customer application is yours.
Hyperscale runs the compiled Product and records its state, receipts and audit
history. Providers perform regulated services. Hyperscale is never the bank,
lender or insurer.

The current estates are sandbox only. Nothing is live and no real bank is
connected. The ledger uses Saudi riyals (SAR) only.

[Documentation](https://hyperscale0.ai/docs) · [Request access](https://hyperscale0.ai/request-access)

## Build and operate

Describe your product to Architect. It proposes HSX changes for review.
The compiler checks the source. You review the changes before applying them
in the Build portal. The portals are Launch, Build and Admin.

People, applications and agents use the same Product operation API.

## Languages and tools

- **HSX** is the language for authoring financial products. Its standard
  library provides reusable financial flows written in HSX.
- **UDL** is the compiled Product contract that the runtime reads.
- **ADL** declares provider adapters that translate between the Product
  contract and provider APIs.

The language tools run independently of the private platform.
