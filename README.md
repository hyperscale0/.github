# .github

Organization-wide defaults for [hyperscale0](https://github.com/hyperscale0).

`profile/README.md` renders on the organization's public profile page.

The community health files here apply to every repository in the organization
that does not ship its own copy: `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`,
`SECURITY.md`, `SUPPORT.md`, `PULL_REQUEST_TEMPLATE.md`, and the issue
templates under `.github/ISSUE_TEMPLATE/`. A repository that adds its own file
overrides the default for that file only.

This repository must stay public for those defaults to apply.
